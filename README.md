## 📖 About The Project

**CREATIVITY** is a single-file, full-stack Flask application designed with a surreal, dark-themed aesthetic. Built to match the exact vibe of a "Creativity never ends" landing page, this project seamlessly blends stunning frontend CSS art (like floating clouds and orbit rings) with a robust Python/SQLite backend.

Whether you're looking to showcase abstract digital art, handle event ticketing, or connect with artists worldwide, this platform does it all from a single script.

## ✨ Key Features

- **Surreal UI & CSS Art:** Custom animations, floating planets, orbit rings, and paper airplanes crafted purely with CSS.
- **Dynamic Art Gallery:** Interactive masonry-style grid with a fully functional Lightbox modal for high-res viewing.
- **AJAX Event Ticketing:** Smooth, page-reload-free ticket booking modal with SQLite database logging.
- **Contact Integration:** Seamless AJAX-powered contact form.
- **Auto-Seeding Database:** Automatically creates and populates the SQLite database (`creativity.db`) with dummy artworks on the first run.
- **Intersection Observers:** Animated number counters that trigger when scrolled into view.
- **Fully Responsive:** Looks perfect on desktops, tablets, and smartphones.
